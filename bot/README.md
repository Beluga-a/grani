# 🤖 Telegram-админка

Бот для редактирования квестов через Telegram. Общается с сайтом по HTTP API.

## 🚀 Установка

### 1. Создай Telegram-бота
1. Открой в Telegram: **@BotFather**
2. Напиши `/newbot`
3. Придумай имя (например: «Грани Страха Админ»)
4. Придумай username (например: `grani_straha_admin_bot`)
5. **Скопируй TOKEN** (выглядит как `1234567890:ABC...`)

### 2. Узнай свой Telegram ID
Открой **@userinfobot** → нажми Start → получишь свой ID (число).

### 3. Установи зависимости
```bash
pip install -r requirements.txt
```

### 4. Настрой переменные окружения

Создай файл `.env` рядом с `admin_bot.py`:

```
BOT_TOKEN=твой_токен_от_botfather
ADMIN_ID=твой_telegram_id
SITE_URL=http://localhost:3000
ADMIN_SECRET=любая_рандомная_длинная_строка

# Supabase Storage — чтобы фото/видео грузились без VPN
# Получи на supabase.com → Settings → API
SUPABASE_URL=https://XXXXXXXXXX.supabase.co
SUPABASE_KEY=eyJ...твой_anon_ключ...
SUPABASE_BUCKET=media
```

⚠️ **`ADMIN_SECRET` должен быть таким же, как в `.env.local` сайта!**

Альтернатива — отредактировать константы прямо в начале `admin_bot.py`.

### 5. Запусти бота

Сначала **запусти сайт** (см. главный README):
```bash
cd ../    # из папки bot/ в корень проекта
npm run dev
```

Потом **в другом терминале** запусти бота:
```bash
cd bot
python admin_bot.py
```

Открой бота в Telegram и напиши `/start`.

## 🎮 Как пользоваться

1. `/start` — список всех квестов кнопками
2. Жмёшь на квест → видишь все его поля и кнопки для каждого
3. Жмёшь на поле (например, «💰 Базовая цена»)
4. Бот покажет текущее значение и попросит новое
5. Пишешь новое → бот сохраняет → возвращаешься к квесту

## 🌐 Когда сайт на хостинге

Поменяй `SITE_URL` на свой домен:
```
SITE_URL=https://granistraha.ru
```

И запускай бота на любом сервере (можно даже на бесплатном хостинге типа Render
или Railway). Главное чтобы `ADMIN_SECRET` совпадал с тем, что задан на сайте.

## 🔐 Безопасность

- Только пользователь с `ADMIN_ID` может управлять ботом — остальные получают «⛔ Доступ запрещён»
- API-эндпоинт защищён секретом `ADMIN_SECRET` — без него запрос отклоняется (401)
- В проде обязательно смени `ADMIN_SECRET` со значения по умолчанию
