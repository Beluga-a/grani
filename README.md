## 🚀 Запуск (для разработки)

### 1. Установи Node.js 18+
https://nodejs.org

### 2. Поставь зависимости
```bash
npm install
```

### 3. Создай файл `.env.local` в корне проекта:
```
ADMIN_SECRET=любая_рандомная_длинная_строка
```
(тот же ключ должен быть в настройках бота — иначе бот не сможет вносить правки)

### 4. Запусти сайт
```bash
npm run dev
```

Сайт откроется на http://localhost:3000

### 5. Запусти бота (отдельным терминалом)

См. инструкцию в `bot/README.md`.

## 🔄 Как это работает

```
       ┌──────────────────┐
       │  data/quests.json │  ← база данных
       └─────────┬─────────┘
                 │
        ┌────────┴────────┐
        │                 │
   ┌────▼─────┐    ┌──────▼──────┐
   │  Сайт    │    │ API /quests │
   │ (Next.js)│    │ (Next.js)   │
   └──────────┘    └──────┬──────┘
                          │
                    ┌─────▼─────┐
                    │ Telegram  │
                    │   бот     │
                    └─────┬─────┘
                          │
                          ▼
                    Telegram-чат
```

1. Сайт читает `quests.json` напрямую (server components)
2. Бот шлёт PATCH-запрос на `/api/quests` с секретом
3. API правит файл, сайт при следующем запросе видит свежие данные

## 🌍 Деплой на хостинг

**Самый простой вариант — Vercel (бесплатно для пет-проектов):**

```bash
npm install -g vercel
vercel
```

Vercel сам всё развернёт. После этого добавь в Settings → Environment Variables:
- `ADMIN_SECRET` — твой секрет

⚠️ **Важно:** на Vercel файл `quests.json` сбрасывается при каждом деплое.
Для постоянного хранения лучше использовать БД (Supabase, Neon, Vercel KV) —
это следующий шаг развития проекта. Скажи когда будешь готов мигрировать.

**Альтернативы:**
- **Render.com** — бесплатно, поддерживает persistent disk (файл сохраняется)
- **VPS** (reg.ru, timeweb, beget — от 200 ₽/мес) — полный контроль

Если понадобится помощь с деплоем — пиши.
